# dsh-agent-protocol

**把同一套工作协议注入当前 profile 下每个智能体的系统提示。**

[English](README.md) | 中文

智能体会漂移：同一件事，这次开篇给任务行，下次直接甩结果；这次改配置前先问，
下次直接覆盖。这个插件把“怎么做事”写成一段固定文本灌进系统提示——先给什么、
怎么压缩口语、何时先加载技能、什么时候必须先问、交付前核对什么——让同一 profile
里的每个智能体遵守同一套规矩。

纯文本插件：只加一个系统提示段，不带工具、不写文件、不联网。

## 注入内容

| 段 | 名称 | 作用 |
|---|------|------|
| 0 | 可见性 | 每条实质回复首行写精炼任务行（15–40 字），按需补「技能 / 假设」标记 |
| 1 | 一次精炼 | 把口语压成一句任务陈述，即执行指令，禁止再写第二版 |
| 1 | 严格模式 | 约束≥3、跨≥3 文件或≥2 子系统、不可逆、>10 分钟、或明确要求严谨 → 输出约束与验收表、缺失先确认、交付逐条自检 |
| 2 | 能力路由 | 按能力语义匹配技能与工具，命中先加载再执行，可串联 |
| 3 | 先问后做 | 七类触发强制反问 1–3 问（带选项与推荐）；读文件/查环境能确认的禁止问 |
| 4 | 团队 | 仅 ≥4 步、可并行、调研→实现→验证、长耗时或明确要求才建队 |
| 5 | 效率与安全 | 独立子任务并行；改删前备份；大文件先检索；结论先行、多用表格 |
| 6 | 交付自检 | 技能声明=加载？验收满足？产物路径给出？覆盖/删除有回退？ |

## 安装

**插件商城**：Discover → 搜索后安装，bundle 只新增一行名为 `agent-protocol` 的 Host 行，
不改动任何 profile 文件。

**本地目录（开发用）**：设置 → 插件 → 添加插件 → 选择本目录；或让智能体调用
`plugin_manager` 的 `install_bundle`。

**npm**：把 `dsh-agent-protocol` 加进 profile 的依赖，并列入该 profile
`package.json` 的 `dsh.profile.bundles`（插件管理器会自动做这两步）。

## 配置

所有开关都在 **设置 → 插件** 里 `agent-protocol` 这一行，改完即时生效，无需重装。

| 键 | 默认 | 含义 |
|---|---|---|
| `language` | `zh` | `zh` 或 `en`，决定注入文本语言 |
| `sectionOrder` | `150` | 该段在系统提示中的排序位置 |
| `taskLine` | `true` | 首行可见任务行 |
| `refine` | `true` | 一次精炼 |
| `strictMode` | `true` | 严格模式及其约束/验收表 |
| `skillRouting` | `true` | 能力路由 |
| `clarify` | `true` | 强制反问（七类触发） |
| `teamPolicy` | `true` | 仅复杂任务建队 |
| `deliveryCheck` | `true` | 交付自检 |

第 5 段「效率与安全」始终存在，它是底线而非开关。

## 实现

`lib/index.js` 导出 Cordis 插件，apply 时只注册一个系统提示段：

    ctx.systemPrompt.section({
      name: 'agent-protocol',
      order: sectionOrder,      // 默认 150
      interpolate: false,
      text: buildText(options),
    })

`buildText` 选中英文模板、按开关丢弃段落、末尾附版本标记。无状态、无存储、
不介入工具执行——卸载 bundle 即彻底移除。

## 边界与隐私

- **是行为指引，不是硬门禁**：模型仍可能偏离，插件不拦截工具调用、不校验产出。
- **仅影响当前 profile**：其他 profile 的智能体看不到这段文本。
- **无副作用**：不写 profile 文件、不联网、无遥测。
- **兼容性**：`engines.dsh` 要求 `>=0.2.2-rc.1 <0.3.0-0`，已在 DSH 0.2.2-rc.5 验证。

## 开发

改 `lib/index.js` 后需要**开新会话**——文本在 apply 时生成，旧会话保留旧版本。
